# Тексты ботов

Все русские фразы, подписи кнопок, сообщения и визуальные маркеры ботов находятся в этом каталоге. Чтобы найти фразу, ищите её здесь, например:

```bash
rg 'Ставки открыты' backend/app/bot/shared/texts
```

## Основные сообщения

| Что меняем | Файлы |
| --- | --- |
| Регистрация игрока | `user/registration.py` |
| Покер и покер рум для игрока | `user/poker.py` |
| Ставки для игрока | `user/betting.py` |
| Опросы | `user/polls.py` |
| Статистика | `user/statistics.py` |
| Общие сообщения игроку | `user/general.py` |
| Заявки и привязка платформ | `admin/registration.py` |
| Управление администраторами | `admin/management.py` |
| Покер для администратора | `admin/poker.py` |
| Ставки для администратора | `admin/betting.py` |

`texts_user.py` и `texts_admin.py` сохраняют прежний интерфейс `Text.user.NAME.value` и `Text.admin.NAME.value`. Значения редактируются в тематических файлах выше.

## Строки, ранее записанные прямо в коде

`inline/telegram/` и `inline/vk/` повторяют структуру обработчиков. Например, текст для VK административного опроса находится в `inline/vk/admin/polls.py`. Подписи кнопок и общие визуальные маркеры лежат в `inline/shared/`. Тексты уведомлений находятся в `inline/telegram/notifications.py` и `inline/vk/notifications.py`.

Некоторые динамические сообщения состоят из нескольких констант с суффиксами `_PART_1`, `_PART_2` и так далее. При изменении такого сообщения проверьте соседние части. Имена констант для VK-событий пока наследуют числовые имена обработчиков; это отмечено в аудите как долг по неймингу.

Технические строки протокола (например, `callback_data`, `action`, HTTP `ok` и ключи состояния) остаются рядом с логикой и не являются редактируемыми сообщениями.
